# 쇼핑몰 장바구니 미니 프로젝트

## 2. 구현 기능
- **상품 목록 조회**: 상품명, 가격, 재고 확인 및 품절 표시
- **상품 담기**: 상품 번호와 수량을 입력하여 장바구니에 추가 (재고 확인)
- **상품 빼기**: 장바구니에 담긴 상품의 수량을 줄이거나 삭제
- **장바구니 조회**: 상품별 수량, 상품 합계, 할인 금액, 배송비 및 최종 결제 금액 확인
- **쿠폰 적용**: 쿠폰 선택 및 할인 적용
  - 10% 할인 (최대 5,000원)
  - 3,000원 할인 (20,000원 이상 구매 시)
- **상품 결제**: 결제 후 상품 재고 차감 및 장바구니 초기화


## 3. 실행 순서

| 번호 | 기능 |
|---|---|
| 1 | 상품 목록 조회 |
| 2 | 장바구니에 상품 담기 |
| 3 | 장바구니에서 상품 빼기 |
| 4 | 장바구니 조회 |
| 5 | 쿠폰 선택 및 적용 |
| 6 | 결제 / 영수증 출력 |
| q | 프로그램 종료 |
